# agustingrassi.github.io
Roadmap: AI &amp; Product Management

Live at **https://agustingrassi.github.io**

## How to update
- **Content** (text, topics, projects): edit `_data/roadmap.yml`
- **Design** (colors, fonts, spacing): edit `style.css`
- **Layout** (page structure): edit `index.html`
- **Behavior** (progress bar, timeline, filters): `roadmap.js`. You rarely need to touch it.

GitHub Pages rebuilds the site automatically 1–2 minutes after each merge to `main`.
